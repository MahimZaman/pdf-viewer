# Simple PDF Viewer

Display PDFs using PDF.js via shortcode.

## Installation and use

Place the `pdf-viewer` directory in `wp-content/plugins/` and activate **Simple PDF Viewer** from the WordPress Plugins screen.

Use `[pdfjs_viewer url="https://example.com/document.pdf" height="600"]` with the URL of your PDF.
